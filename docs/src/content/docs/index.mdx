## Why

Ask a model what another model costs and it answers from training data that was stale before it shipped: retired prices, missing models, wrong context windows. tokencost gives your assistant a tool instead of a memory — live data for 4,400+ models from the registry LiteLLM uses for its own cost tracking, plus the arithmetic for tiered pricing, prompt caching, and cross-provider comparison.

## See it in action

![tokencost demo — ask pricing questions in natural language and get instant answers](/tokencost-dev.gif)

## Install

Add to your Claude Code config in one command:

```bash
claude mcp add tokencost-dev -- npx -y tokencost-dev
```

Or add the JSON config manually — see the [Getting Started](/getting-started/) guide for VS Code, Cursor, Windsurf, and more.

## What can it do?

<CardGrid stagger>
  <Card title="Model Lookup" icon="open-book">
    Look up pricing, context windows, and capabilities for any LLM. Fuzzy matching means you don't need exact model IDs.
  </Card>
  <Card title="Cost Estimation" icon="pencil">

  </Card>

  </Card>

## Example: batch cost planning

> "How much would it cost to run Claude Opus 5.5 vs Sonnet 5.5 for 10K requests, averaging 2K input and 500 output tokens each?"

```
Claude Opus 5.5:   $180.00  (Input: $80 + Output: $100)
Claude Sonnet 5.5:  $90.00  (Input: $40 + Output: $50)
```

Sonnet is half the price — saving $90 per 10K-request batch.
